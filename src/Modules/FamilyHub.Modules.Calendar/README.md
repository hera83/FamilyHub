# Modul: Kalender

**Status:** skelet – kun modul-registrering og en "på vej"-side.

## Tanker til indhold (ikke besluttet)

- Familiens delte Google-kalender vist for dagen og ugen, stort og læsbart på afstand.
- Farve pr. familiemedlem (fra `IHouseholdService` → `FamilyMember.Color`).
- Widget på forsiden: "I dag" og "Næste aftale".
- Synkronisering i baggrunden (hosted service) med cache, så skærmen virker, selvom nettet driller.
- Oprettelse af aftaler: dato og tid vælges med pickere/steppere, kun titlen skrives.

Byg modulet efter [docs/standarder/nyt-modul.md](../../../docs/standarder/nyt-modul.md).
