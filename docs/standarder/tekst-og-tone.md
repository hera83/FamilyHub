# Tekst og tone

Family Hub taler dansk til hele familien – også børnene. Teksten skal være kort, venlig og rolig.

## Grundregler

- **Dansk overalt**, du-form, korte sætninger. Venlig, ikke smart eller jokende.
- **Knapper er verber i bydeform:** "Gem", "Tilføj vare", "Slet", "Forbind". Aldrig "OK", "Ja" eller "Submit".
- **Titler med stort kun i starten:** "Ugens madplan" – ikke "Ugens Madplan".
- **Ingen udråbstegn** i almindelige beskeder.
- **Fejl:** hvad der skete + hvad man kan gøre. Aldrig tekniske detaljer, fejlkoder eller skyld.
- **Tomme tilstande:** hvad der kommer her, og hvordan man kommer i gang.
- **Tal og datoer på dansk** – brug altid `DanishFormat`:
  "Fredag 25. september", "I dag", "I morgen", "uge 39", "18:30", "1,5 kg".
- Citationstegn i tekst: »…«.

## Faste ord

| Brug | Undgå |
|---|---|
| Familiemedlem | Bruger, profil |
| Skærm, denne skærm | Device, enhed, klient |
| Indstillinger | Settings, opsætning |
| Tilføj | Opret, ny (som verbum) |
| Redigér | Ændr, edit |
| Fjern (fra en liste) | Slet (når det kan fortrydes) |
| Slet (permanent) | Fjern (når det ikke kan fortrydes) |
| Fortryd | Undo, annuller handling |
| Annuller (luk uden at gemme) | Afbryd, tilbage |
| Færdig | OK, luk |

## Eksempler

| Situation | Skriv | Ikke |
|---|---|---|
| Gemt | "Gemt" / "Navnet er gemt" | "Ændringerne blev gemt succesfuldt!" |
| Fjernet fra liste | "Mælk er fjernet" + Fortryd | "Er du sikker på, at du vil slette dette element?" |
| Kunne ikke gemme | "Kunne ikke gemme" – "Prøv igen om lidt." | "Fejl 500: Internal Server Error" |
| Ikke forbundet | "Google Kalender er ikke forbundet" – "Familiens aftaler kan ikke vises, før kalenderen er forbundet." | "Autentificering mangler" |
| Tom liste | "Indkøbslisten er tom" – "Tilføj den første vare." | "Ingen data" |
| Validering | "Skriv et navn" | "Feltet er påkrævet" |
| Bekræftelse | "Slet madplanen for uge 39?" [Annuller] [Slet] | "Er du sikker?" [Nej] [Ja] |
